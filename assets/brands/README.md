# E-wallet brand SVG sources

The SVG files in this directory are downloaded from Wikimedia Commons Special:FilePath URLs and retained as local assets so the app does not depend on a live network request for account icons.

| `linkaja.svg` | `LinkAja.svg` | https://commons.wikimedia.org/wiki/File:LinkAja.svg | See source page |

The app uses these files only for account identification. It does not claim affiliation with any brand. When a brand-specific SVG is not available, the account editor offers a neutral wallet icon rather than substituting a different brand logo.
